> **EduVault** (formerly *Ściąga Technologiczna*) is a modern, responsive web application designed as an all-in-one study guide and cheat sheet hub for high school students. It provides organized, chapter-by-chapter revision materials across multiple core academic subjects.

---

## 🌟 Key Features

- 📖 **Categorized Subject Modules**: Quickly jump into dedicated study sections tailored for specific high school courses.
- 📱 **Fully Responsive Layout**: Built with a mobile-first approach using Bootstrap, ensuring seamless viewing across desktop, tablet, and mobile devices.
- ⚡ **Lightweight & Fast**: Pure static web application with minimal dependencies for instant page loads.
- 🎯 **Intuitive Navigation**: Clean UI allowing students to browse chapters and topics effortlessly.

---

## 📚 Covered Subjects

- 🇨🇳 **Chinese Language** (`Język Chiński`) — Grammar rules, vocabulary notes, and chapter breakdowns.
- 🧪 **Chemistry** (`Chemia`) — Chemical formulas, reactions, and core concepts.
- 📜 **History** (`Historia`) — Chronological historical events, eras, and key figures.
- 🧬 **Biology** (`Biologia`) — Biological processes, anatomical definitions, and diagrams.
- 🏛️ **Philosophy** (`Filozofia`) — Key philosophical theories, timelines, and thinkers.
- 🌍 **History & Contemporary Studies** (`Historia i Teraźniejszość`) — Modern political history and social issues.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **UI Framework**: Bootstrap 4
- **Typography**: Google Fonts (Open Sans)
- **Icons & Media**: Custom images and icons

---

## 🚀 Quick Start

Since **EduVault** is a static web application, no build tools or server setups are required!

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/EduVault.git
   ```
2. **Open in browser**:
   Simply double-click `index.html` or serve it using any local static web server (e.g. VS Code *Live Server*).
